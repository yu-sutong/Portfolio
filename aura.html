Aura

AI-powered dating web application

Aura is an AI-powered dating application built by Yu Sutong. The product aims to reduce swipe fatigue by using personalized agents to screen candidate matches and reason about compatibility before users spend time on low-signal conversations.

Summary

The application uses a modern web stack and an AI-assisted matching system to make dating discovery feel more intentional and less repetitive. It explores how language models can support compatibility reasoning in a consumer-facing product experience.

Design goals

  • Reduce endless swiping by adding AI-based pre-screening.
  • Provide more grounded compatibility scoring than surface-level profile browsing.
  • Present dating as a higher-trust product experience built around personalization.

Technology

  • Frontend: React, Tailwind CSS
  • Backend and data: Supabase
  • AI layer: LLM-assisted matchmaking workflows
