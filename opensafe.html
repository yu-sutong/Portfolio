OpenSafe

Zero-trust AI security middleware

OpenSafe is a zero-trust security middleware built during the TinyFish Hackathon to protect autonomous AI agents from indirect prompt injection attacks and malicious hidden payloads while browsing the web.

Summary

The project routes agent web requests through an isolated cloud browser, renders dynamic JavaScript safely, and uses OpenAI-powered semantic sanitization to strip malicious instructions from the DOM before returning clean content to the local agent.

Purpose

  • Protect autonomous agents from hostile web content and hidden payloads.
  • Demonstrate a practical defense layer for indirect prompt injection attacks.
  • Combine isolated browsing, middleware inspection, and model-based sanitization in one workflow.

Technology

  • Frontend: React, Next.js, Tailwind CSS
  • Backend: Vercel Serverless Functions
  • Security stack: isolated cloud browser (TinyFish), OpenAI-based DOM sanitization
