ReUnion

Hack&Roll 2026 travel planning application

ReUnion is a travel-planning application built at Hack&Roll 2026. It calculates affordable meetup cities for friends in different locations by evaluating multiple routes and ranking candidate hubs with fairness-aware pricing logic.

Summary

The product was built as a lightweight web experience that compares travel options across possible meetup locations. It focuses on helping groups coordinate around a shared destination in a way that feels fair and easy to evaluate.

Purpose

  • Help distributed friend groups coordinate more realistic reunions.
  • Avoid planning bias by considering the cost burden on each participant.
  • Turn flight search into a group decision tool instead of a solo booking task.

Technology

  • Frontend: React, TypeScript, Tailwind CSS
  • Backend: Supabase
  • Integrations: Travel search APIs
