# Yu Sutong Wiki

Wikipedia-style personal portfolio for Yu Sutong.

## Structure

- `index.html`: main profile page
- `aura.html`, `reunion.html`, `shopspot.html`, `shwipes.html`, `snakeye.html`: project pages
- `styles.css`: shared site styling
- `assets/images/`: profile, travel, and project screenshots

## Deploy

This is a static site and can be deployed directly on Vercel with the default static-site settings.
