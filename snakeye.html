SnakEye

Face-tracking game project

SnakEye is a reimagining of the classic snake game that uses face tracking and head movement as the primary input method.

Summary

The project experiments with computer vision as a game input method, replacing keyboard controls with face-tracking interaction for a playful real-time experience.

Notability

SnakEye was submitted to Hack&Roll 2024.
